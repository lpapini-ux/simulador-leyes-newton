SIMULADOR DE LEYES DE NEWTON - 

Escenarios de la Segunda Ley:
1. Superficie plana
2. Plano inclinado
3. Polea Atwood
4. Bloques conectados

Reglas de entrada:
- Gravedad fija: 9.81 m/s².
- Un campo de friccion vacio se interpreta como mu = 0.
- Bloques conectados acepta Masa C = 0 para trabajar con dos bloques.
- Si Masa C > 0, se trabaja con tres bloques.

Cada escenario presenta 8 tarjetas de resultados relevantes.
El desarrollo matematico se muestra debajo de las tarjetas.
