SIMULADOR DE LEYES DE NEWTON - VERSION WEB

Archivos:
- app.py: interfaz web hecha con Streamlit.
- requirements.txt: dependencia para instalar Streamlit.
- main.py, interfaz.py, leyes_newton.py, fuerzas.py, validaciones.py: version de escritorio original y modulos originales.

Para publicar:
1. Sube los archivos al repositorio GitHub.
2. En Streamlit Community Cloud, crea una app desde ese repositorio.
3. Selecciona app.py como archivo principal.

Nota: app.py es independiente de Tkinter y presenta cuatro escenarios.
Se conservó la convención de signos del código original para el plano inclinado.
Conviene validar esa convención física antes de presentar resultados definitivos.
